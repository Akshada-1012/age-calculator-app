# 🚀 Age Calculator App

A cloud-based Age Calculator Web Application built using Python (Flask), containerized using Docker and deployed on Microsoft Azure.

## 🔧 Tech Stack
- Python (Flask)
- HTML/CSS
- Docker
- Microsoft Azure
- Git & GitHub

## 🌟 Features
- Calculates exact age from Date of Birth
- Dockerized application
- Cloud deployment on Azure
- Simple and clean UI

## ☁️ Deployment
The application is deployed on Microsoft Azure as a containerized web app.
